# 维护公开目录

需要 Node.js 22.13.0 或以上，无额外 npm 依赖。此仓库公开比较资料和维护脚本，网站应用源码单独维护。

## 从网站目录导出

在本仓库执行，`--source` 指向维护者持有的 APIpk 网站源码根目录：

```bash
npm run export -- --source ../APIpk-website
npm run generate
npm test
npm run validate
```

导出器复用网站中的公开渠道过滤、价格核验与可比条件。公开字段明确选择，来源日期保持原值，所有候选数据通过检查后才写入。它不会读取 `.env`、生产运行数据库或用户生成记录，也不会进行网络采集、调用生图或提交 Git。

没有数据变化时，内容哈希、最近有效变更时间和变更记录保持不变。目录为空、字段异常或含私有链接时导出失败，保留旧 JSON。运行时数据库审核结果不在静态快照范围中。

## 修改已公开资料

维护者可修正 `data/` 中的记录，但正式更新应先在网站维护源中完成核对，再重新导出，避免两处数据长期分叉。手工变更同样需要同步 `metadata.json` 的内容哈希并通过校验；推荐使用导出器完成。

README、型号详情、渠道索引、免费规则、样图页、变更和移出说明由 `npm run generate` 生成，修改数据后重新生成。方法、FAQ、关系披露和使用指南为人工维护文档。

每次提交触发 GitHub Actions：测试、数据/文件校验、重新生成后检查差异。工作流仅有 `contents: read` 权限，不自动写仓库；当前没有每日定时采集、自动推送、部署或付费测评任务。

## 公开文件清单

- `data/`：型号、渠道、报价、免费规则、样图来源、移出状态、内容哈希及有效变更。
- `docs/`：生成的查阅索引、方法、FAQ、关系披露和品牌/页面截图。
- `public/samples/`：已存在的样图 WebP 预览，不含原图包。
- `scripts/`、`tests/`、`.github/`：本目录的导出、生成、验证和反馈入口。

不公开网站应用源码、用户参考图、用户生成记录、Key、个人账号/账单、运行数据库、私有配置或本机验收日志。校验器检查允许的文件路径、JSON 关联、缺失价格、来源链接、图片哈希和相对文档链接。
