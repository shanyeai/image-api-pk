# 常见问题

## 这是提示词合集吗？

主要内容是生图型号、图片 API 渠道、报价、免费规则与图片预览。提示词用于说明相同任务，评分对象应是生成图片；本仓库当前没有科研评分器的复现结果。

## “PK”现在能证明什么？

可以比较公开报价的规格和适用条件、直观看现有样图。样图来自同一渠道，不能证明不同中转站哪个更好。跨渠道完整批次和盲评尚未完成。

## 为什么有价格却没有推荐星级？

核对官网价格不证明模型身份、真实扣费和长期稳定性。没有这些证据，不生成综合排名；不足的资料保留待核实状态。

## 免费网页意味着免费 API 吗？

不意味着。两种资格各自标注；额度、积分和试用期限按来源规则解释。网页免费不能直接用于推断免费 API 的张数。

## 为什么 README 的日期不是每天改变？

无变化的导出不会改变最近有效内容变更日期，来源资料也保留其核对时间。当前未配置每日来源采集。

## 如何实测自己的 Key？

打开[网站测试页](https://apipk.site/model-test)，按页面支持的 OpenAI 兼容 Images 接口填写渠道地址、型号和自己的 Key。真实调用按对应渠道计费，不向 GitHub 提交 Key 或账单。

## 如何反馈错误？

使用[纠错或收录表单](https://github.com/shanyeai/image-api-pk/issues/new/choose)，附精确型号、尺寸/质量、官网链接、核对日期与正确内容。[贡献说明](../CONTRIBUTING.md)
