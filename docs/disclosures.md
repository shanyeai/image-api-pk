# 维护与关系披露

APIpk 网站及本仓库由维护者编辑、整理和发布。来源报价、公开样图与外部资料分别保留来源；收录顺序、样图数量和价格不会自动生成推荐星级。

当前样图来自 ImgAPI 的公开展示页面。相同来源的样图不能用来判断不同渠道的效果差异，网站和仓库收录也不表示该渠道得到独立实测背书。

维护者尚未提供完整的逐渠道自营、商业合作或返佣关系清单，因此本仓库不声明所有收录均为完全独立或无推广关系。后续关系信息应补充渠道、关系类型、生效时间和公开依据；关系披露不能替代测试证据。

有关系信息需补充或存在利益冲突时，可使用[待核实反馈](https://github.com/shanyeai/image-api-pk/issues/new/choose)。
