# 数据与比较方法

## 报价

按精确请求型号、渠道方案、生成方式、尺寸、质量和输出张数比较。固定按张、输入输出 Token 和订阅套餐分别记录。缺少价格使用 `null`，不按零元排序；缺少质量说明不外推到 Low、Medium、High 等档位。

价格标记为“官网报价已核对”表示公开页面或公开接口的报价资料已记录来源与日期，不表示已实测扣费、接口可用或模型身份。人民币换算参考汇率单独保存在 [快照摘要](../data/metadata.json)，不包含支付手续费。详情展示原币种报价。

公开目录复用网站的 `applyPriceAudit`、`publishedCatalog` 和 `quoteEligibility` 规则，排除已移出的价格渠道。导出仅使用网站静态目录，不读取生产数据库、用户投稿、账户或订单；网站运行时审核库的额外内容不在此快照中。

## 图片

模型效果比较的行是型号，列是场景；同一列使用相同提示词。当前 18 张图片为同一渠道的公开展示样图，采集时间保留原值，未由本仓库重新生成。页面“全模型”指已展示的型号，不表示覆盖市场全部模型。

仓库只包含 WebP 预览，原图链接、尺寸与 SHA-256 保存在 [样图索引](../data/samples.json)。样图名称沿用来源，不以图片外观证明原厂模型身份。第三方素材权利见[版权说明](../COPYRIGHT.md)。

## 渠道实测

跨渠道 PK 需要固定请求型号/SKU、提示词、尺寸、质量、参考图、每组生成数量和选图规则。保存每次成功与失败、请求和实际尺寸、端到端耗时、实际扣费依据及原图，不能只展示精选结果。

当前公开快照没有付费跨渠道批次和人类盲评投票，不生成成功率、最快/最稳定结论、综合星级或 Elo 排名。官网报价和公开样图不能填补这些字段，实际扣费与实测时间保持 `null`。

## 图片评分

ImageReward、HPSv2、PickScore 等以提示词和生成图片为输入，辅助预测偏好；GenEval 等检查生成图片是否满足任务约束。它们并非纯提示词合集，但本公开仓库尚未运行这些评分器。

网站现有视觉分析是单图辅助分析，不是统一批次的盲评对战。AI 评审、人工偏好、外部榜单和来源声明分别标注，不将辅助分数写成模型真实性概率。

## 更新与纠错

来源核对时间、样图采集时间和公开内容变更时间各自保留。重复导出没有内容变化时不刷新日期；失败不覆盖之前的有效快照。导出、文档生成和校验需完成后再由维护者发布。

资料不足时保留待核实状态。投诉、价格无法访问或维护者移出目录均不单独证明跑路，见[移出说明](exclusions.md)。纠错附公开来源与日期，见[贡献说明](../CONTRIBUTING.md)。
